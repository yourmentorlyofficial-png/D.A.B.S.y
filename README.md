# DABSy ✦

DABSy is a mobile-first personal assistant PWA.

## Current V1 features

- Mobile-first interface
- Responsive design
- Glassmorphism UI
- Dark/light mode
- Installable PWA
- Offline app shell
- Service worker
- Local theme persistence
- Quick-action interface
- Bottom navigation
- Safe-area support for phones

## Structure

- `index.html` → application structure
- `style.css` → interface and responsive styling
- `app.js` → interactions and PWA installation
- `manifest.webmanifest` → PWA metadata
- `sw.js` → offline caching
- `icon-192.svg` → application icon
- `icon-512.svg` → application icon

## Deployment

DABSy should be served over HTTPS.

GitHub Pages is suitable for the static PWA.
